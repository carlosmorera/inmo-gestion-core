# Skills del proyecto

La carpeta `skills/` es la fuente canónica. Para compatibilidad:

```bash
mkdir -p .agents .opencode
ln -s ../skills .agents/skills
ln -s ../skills .opencode/skills
```

Si el sistema o Git no conserva enlaces simbólicos, copiar las carpetas manteniendo exactamente el mismo contenido y actualizar primero la fuente canónica.
